# Food Construct — лабораторная работа №8 (offline/fallback)

Эта версия нужна для демонстрации, пока учебные API Московского Политеха отвечают 502.

Сначала сайт всё равно делает `fetch()` к API. Если загрузить меню не удалось, он автоматически использует локальную копию 30 блюд и локальные изображения. `localStorage`, новая страница «Оформить заказ», удаление блюд, пересчёт стоимости, sticky-панель и проверка комбо работают полностью.

## Отправка заказа

POST заказа по условию ЛР №8 всё равно выполняется только на настоящий API. Для него нужен персональный ключ в `config.js`:

```js
const API_KEY = "ВАШ-КЛЮЧ";
```

Если API недоступен, появится уведомление об ошибке, а выбранные блюда останутся в `localStorage`, как требует задание.

Для сдачи при работающем сервере предпочтительнее использовать `lab8_food_construct_api.zip`.
