# Основы веб-технологий — лабораторные работы №1–10

Репозиторий содержит последовательное выполнение лабораторных работ по дисциплине **«Основы веб-технологий»**.  
Проект развивается от простой HTML/CSS-вёрстки до JavaScript, работы с REST API, `localStorage`, CRUD-операций и адаптивного лендинга на Bootstrap.

**Учебный проект:** Food Construct  
**Группа:** 241-327

## API- и offline/fallback-версии

Начиная с ЛР №7 проект зависит от учебного API Московского Политеха. Во время выполнения работ сервер периодически возвращал `502 Bad Gateway`, поэтому рядом с основными версиями сохранены резервные папки **«без сервера»**.

### Основные версии

Папки без приписки `без сервера` предназначены для проверки работы с настоящим учебным API. В них сохраняются `fetch`-запросы и логика взаимодействия с сервером, предусмотренная заданиями.

### Версии «без сервера»

Папки с припиской `без сервера` предназначены для демонстрации интерфейса и клиентской логики, если учебный API временно недоступен.

- ЛР №7 использует локальную копию меню при ошибке API.
- ЛР №8 позволяет проверить выбор блюд, `localStorage`, оформление и интерфейс заказа даже при проблемах с сервером.
- ЛР №9 дополнительно использует локальные демонстрационные заказы для просмотра, изменения и удаления.
- ЛР №10 сохраняет Bootstrap-лендинг и содержит fallback-логику предыдущих этапов проекта.

Для сдачи при работающем API рекомендуется открывать **основную версию** соответствующей лабораторной.

## Как запускать

Рекомендуемый способ:

1. Открыть репозиторий в **Visual Studio Code**.
2. Установить расширение **Live Server**.
3. Перейти в папку нужной лабораторной.
4. Запустить требуемую страницу через **Open with Live Server**.

Основные страницы проекта:

- `index.html` — страница «О нас»;
- `lunch.html` — выбор блюд;
- `order.html` — оформление заказа, начиная с ЛР №8;
- `orders.html` — история и управление заказами, начиная с ЛР №9;
- `landing.html` — Bootstrap-лендинг в ЛР №10.

Запуск через Live Server особенно важен для лабораторных, использующих `fetch()` и API.

## Лабораторная работа №10

ЛР №10 продолжает проект ЛР №9, но основная новая часть — отдельная страница `landing.html`.

В ней реализованы:

- Bootstrap 5;
- Bootstrap Grid System;
- адаптивная навигация;
- hero-блок;
- блок преимуществ;
- CTA-блок с переходом к сборке ланча;
- контактная секция;
- форма обратной связи;
- адаптация для мобильных устройств.

В репозитории находятся две версии ЛР №10:

- `Лабораторная работа №10` — основная версия с настоящим учебным API на страницах меню и заказов;
- `Лабораторная работа №10 без сервера` — резервная версия для демонстрации, если API недоступен.

Сам `landing.html` не требует учебного API. Bootstrap и Google Fonts подключаются через CDN, поэтому для их загрузки требуется интернет.

## Персональный API key

В лабораторных №8–10 для операций с заказами используется персональный API key учебного сервера.

> Если репозиторий будет **публичным**, не рекомендуется публиковать персональные ключи. Перед публикацией замените значение ключа в `config.js` на заглушку и добавьте его локально перед проверкой. Если преподавателю нужен готовый рабочий вариант с ключом, безопаснее использовать приватный репозиторий и предоставить преподавателю доступ.

Ключ Яндекс.Карт к этим лабораторным Food Construct не относится и в репозиторий не включён.

## Примечание о доступности API

Если при открытии ЛР №7–10 появляется сообщение вроде `Failed to fetch` или сервер возвращает `502 Bad Gateway`, это означает, что учебный API в данный момент недоступен. Для демонстрации можно открыть соответствующую папку **«без сервера»**.
