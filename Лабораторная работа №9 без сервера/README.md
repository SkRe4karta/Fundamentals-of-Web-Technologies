# Food Construct — лабораторная работа №9 (offline/fallback)

Это демонстрационная версия на случай, если учебный API Московского Политеха недоступен (например, отвечает 502).

Сначала приложение пытается использовать настоящий API. Если запрос не проходит, меню берётся из локальной копии, а история заказов — из демонстрационного хранилища `localStorage`. В offline-режиме работают просмотр, редактирование, удаление и создание заказа, чтобы можно было показать интерфейс и логику лабораторной без доступного сервера.

Для сдачи при работающем API используйте `lab9_food_construct_api.zip`.

## Что реализовано

- история заказов с сортировкой по дате;
- модальное окно просмотра;
- модальное окно редактирования;
- модальное окно подтверждения удаления;
- обновление списка после изменения/удаления;
- уведомления об успешных операциях и ошибках;
- сохранена вся функциональность предыдущих лабораторных;
- подписи фильтров начинаются с заглавной буквы.

## Сброс демонстрационных заказов

В DevTools можно удалить ключ `foodConstructOfflineOrdersLab9` из Local Storage. После обновления страницы снова появятся три демонстрационных заказа.
