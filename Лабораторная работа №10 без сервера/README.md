# Food Construct — лабораторная работа №10

Лабораторная работа №10 выполнена как продолжение предыдущих лабораторных проекта Food Construct. Основная новая часть — адаптивный лендинг, сверстанный на Bootstrap 5 с использованием Bootstrap Grid System.

## Что добавлено в ЛР №10

- отдельная страница `landing.html`;
- Bootstrap 5;
- адаптивная навигация с `navbar-toggler`;
- hero-блок с названием сервиса, описанием и изображением;
- секция преимуществ;
- CTA-кнопка перехода к странице «Собрать ланч»;
- блок контактов;
- форма обратной связи;
- адаптация колонок для планшетов и смартфонов;
- ссылка «Лендинг» добавлена в навигацию остальных страниц Food Construct.

## Две версии проекта

Для удобства проверки подготовлены две версии ЛР №10.

### API-версия

Папка `lab10_food_construct_api` — основная версия для сдачи. Страницы, которые используют данные меню и заказов, обращаются к учебному API Московского Политеха. Персональный `api_key` уже указан в `config.js` и передаётся в запросах, где это требуется.

Если учебный API временно отвечает 502 или недоступен, API-версия показывает ошибку загрузки. Это ожидаемое поведение строгой версии: данные не подменяются локально.

Сам `landing.html` от API не зависит и продолжает работать, если Bootstrap CDN доступен.

### Offline/fallback-версия

Папка `lab10_food_construct_offline` предназначена для демонстрации проекта во время недоступности учебного API. Сначала она пытается выполнить обычный запрос к серверу, но при ошибке автоматически использует локальную копию блюд.

Для истории заказов fallback-режим использует `localStorage`, поэтому просмотр, создание, редактирование и удаление заказов можно проверить даже при 502 со стороны учебного API.

Слово `offline` здесь относится к резервной работе без учебного CRUD API. Google Fonts и Bootstrap CDN по-прежнему требуют интернет-соединения.

## Структура основных файлов

```text
landing.html     — лендинг ЛР №10
landing.css      — дополнительные стили лендинга
index.html       — страница «О нас»
lunch.html       — выбор блюд
order.html       — оформление заказа
orders.html      — история заказов
config.js        — API key и адреса API
api.js           — функции запросов к API
```

В offline/fallback-версии дополнительно есть `fallback-dishes.js` с локальной копией меню.

## Как запускать

Откройте нужную папку проекта в VS Code и запустите `landing.html` или `index.html` через Live Server.

Для сдачи рекомендуется использовать API-версию. Offline/fallback-версия нужна как резервная демонстрация, если сервер Московского Политеха временно недоступен.
