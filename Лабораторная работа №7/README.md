# Food Construct — лабораторная работа №7

Продолжение лабораторной работы №6.

## Что изменено в ЛР №7

- Добавлена функция `loadDishes()`.
- Основной источник меню — API через `fetch()`:
  `https://edu.std-900.ist.mospolytech.ru/labs/api/dishes`.
- После получения JSON карточки блюд создаются динамически.
- Если учебный API временно возвращает ошибку (например, 502), сайт автоматически использует локальную резервную копию данных из `fallback-dishes.js`. Это позволяет демонстрировать работу страницы во время сбоя сервера, при этом код запроса к API остаётся в проекте.
- Если из API пришли данные, но сервер изображения недоступен, карточка автоматически подставляет локальную копию изображения.
- Сохранены функции предыдущих лабораторных: сортировка, фильтрация, выбор блюда, замена блюда той же категории, расчёт стоимости, проверка состава заказа и уведомления ЛР №6.
- Подписи фильтров начинаются с заглавной буквы.

## Запуск

Откройте папку проекта в VS Code и запустите `lunch.html` через Live Server.
