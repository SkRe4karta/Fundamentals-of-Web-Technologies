# Food Construct — лабораторная работа №6

Продолжение лабораторной работы №5.

## Что добавлено

- Блок **«Доступные для заказа комбо»** с 5 допустимыми вариантами ланча.
- Отдельный блок с десертом: десерт можно добавить к любому комбо.
- Комбо выведены CSS Grid (3 колонки на широкой странице).
- Каждый вариант и каждое блюдо внутри него оформлены flex-контейнерами.
- Для иконок реализован hover через `transform: translateY(...) scale(...)`.
- Перед отправкой формы JavaScript проверяет, соответствует ли набор блюд одному из допустимых комбо.
- Если набор неверный, отправка формы блокируется и динамически создается одно из 5 уведомлений из задания.
- Уведомление имеет `position: fixed`, расположено поверх страницы и отцентрировано.
- Кнопка «Окей 👌» меняет фон и цвет текста при наведении и удаляет уведомление из DOM при нажатии.
- При корректном комбо форма продолжает отправляться POST-запросом на `https://httpbin.org/post`, если остальные обязательные поля заполнены.

## Допустимые комбо

1. Суп + главное блюдо + салат + напиток
2. Суп + главное блюдо + напиток
3. Суп + салат + напиток
4. Главное блюдо + салат + напиток
5. Главное блюдо + напиток

Десерт можно добавить к любому из вариантов.

## Запуск

Откройте папку в VS Code и запустите `lunch.html` через Live Server.
