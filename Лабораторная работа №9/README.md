# Food Construct — лабораторная работа №9 (API)

Продолжение лабораторной работы №8.

## Что реализовано

- Страница `orders.html` с историей заказов текущего пользователя.
- Заказы загружаются через `GET /labs/api/orders` и сортируются по убыванию даты оформления.
- Для каждого заказа выводятся номер, дата оформления, состав, стоимость, время доставки и действия.
- «Подробнее» открывает модальное окно с полной информацией о заказе.
- «Редактирование» открывает форму с текущими значениями заказа. Редактируются только `full_name`, `email`, `phone`, `delivery_address`, `delivery_type`, `delivery_time`, `comment`.
- Сохранение изменений выполняется запросом `PUT /labs/api/orders/{id}`.
- Удаление подтверждается отдельным модальным окном и выполняется запросом `DELETE /labs/api/orders/{id}`.
- После изменения или удаления история заказов загружается заново.
- Ошибки и успешные операции отображаются уведомлениями.
- Сохранены все предыдущие страницы и функциональность ЛР №1–8.
- Подписи фильтров сохранены с заглавной буквы: «Рыбный», «Мясной», «Холодный», «Горячий» и т. д.

## API key

Откройте `config.js` и вставьте персональный API key из СДО:

```js
const API_KEY = "ВАШ-КЛЮЧ";
```

Без персонального ключа загрузка, редактирование и удаление заказов через API работать не будут.

## Запуск

Откройте проект в VS Code и запустите через Live Server. Основная новая страница — `orders.html`.
