# Food Construct — ЛР №7 — offline/demo версия

Эта версия нужна для демонстрации, когда оба учебных API Московского Политеха недоступны или отвечают 502.

## Как работает

- Сначала `loadDishes()` пробует получить меню через `fetch()` с обоих API из задания.
- На каждый адрес установлен тайм-аут 4 секунды.
- Если API работает, используются серверные данные.
- Если оба API недоступны, автоматически подключается `fallback-dishes.js` и локальные изображения.
- Фильтры, выбор блюд, итоговая стоимость и проверка состава заказа работают в обоих режимах.

## Важно

Это удобная демонстрационная версия. Формальное требование ЛР №7 — загружать все блюда через API, поэтому для сдачи при работающем сервере используйте API-версию.

## Запуск

Откройте проект через Live Server / localhost и запустите `lunch.html`.
